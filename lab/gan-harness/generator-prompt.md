# Generator Prompt Template

This file is the *template* used by `lab/scripts/generate.mjs` to build the
exact prompt handed to the Generator. The script inlines:

- `{{SPEC}}` — contents of `lab/gan-harness/spec.md`
- `{{RUBRIC}}` — contents of `lab/gan-harness/eval-rubric.md`
- `{{CHAMPION_ID}}` — id of the variant that won the previous round
- `{{CHAMPION_SOURCE}}` — full source of `lab/variants/queen/<id>.mjs`
- `{{LINEAGE}}` — table of every existing manifest entry
- `{{NEXT_IDS}}` — comma-separated list of next-available IDs (e.g. `v004,v005,v006`)
- `{{COUNT}}` — N (length of `NEXT_IDS`)
- `{{TIMESTAMP}}` — ISO timestamp the script will assign to `@generatedAt`

Do not edit this file expecting the lab UI to pick it up at runtime — the
script reads it from disk per invocation.

---

# Prompt

You are the **Generator** half of a GAN-style design loop. The
**Evaluator** is a human picking winners in a 2x2 lab UI; you do not see
their reasoning, only the next champion they hand back.

Your task: produce {{COUNT}} new queen-shockwave variants seeded from the
current champion `{{CHAMPION_ID}}`. Each variant must obey the spec
verbatim and target the rubric.

## Spec (verbatim)

{{SPEC}}

## Rubric (verbatim)

{{RUBRIC}}

## Current champion: `{{CHAMPION_ID}}`

```js
{{CHAMPION_SOURCE}}
```

## Lineage so far

{{LINEAGE}}

## Your output

Write exactly {{COUNT}} variants, using these IDs in order:
**{{NEXT_IDS}}**.

Each variant must be a single block in this format — the parser depends
on it:

```
=== VARIANT: <id> ===
<full file contents, including the JSDoc header and the export>
=== END VARIANT ===
```

Set `@generatedAt {{TIMESTAMP}}` in every header (the script will not
overwrite it). Set `@parent {{CHAMPION_ID}}` in every header. Set
`@generatedBy claude-skill`.

Between variant blocks you may write nothing — no commentary, no
explanation, no markdown. The parser ignores anything outside the
`=== VARIANT ... === END VARIANT ===` fences, but extra text wastes
tokens and confuses future readers of the round log.
